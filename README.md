# Auto Hotkey

A auto_hotkey program I made to prevent my stupid classmate ever typing poop shit on my whatsapp web while my laptop opens

## Installation

Inside this repo, I provided two format `.exe` and `.ahk`. Use `.exe` if you don't care about building it from source, a.k.a., ready to use. Use `.ahk` if you have Auto hotkey installed, and you prefer to modify the script directly.

## Automatic Load on Startup (Recommended)

The initial reason I made this script is for the script to automatically run whenever your device boot up. To do this, follow the given instruction below:

1. Create a shortcut of the program (whether `.exe` or `.ahk`) via Right-Click on the program, and select "Create shortcut".
2. Copy this shotcut
3. Click `<Windows + R>` to open 'Run' on Windows
4. Type `shell:startup`, or if that does not work, go to your startup folder
5. Paste your shortcut inside the Startup folder
6. Done!

What happen is that, the program will run automatically whenever this device is booted up.

## Usage

On your device, click `<Windows + Alt + />` to open a help message.

Note: If that does not work, your `<Win>` keybind might be switched with `<Fn>`, try clicking `<Fn>` instead.
